If you’re trying to collect *every* DSA technique, don’t chase an endless list—organize them into patterns. Once you see the patterns, most problems reduce to a handful of ideas used cleverly.

Here’s a **complete, structured map of DSA techniques** 👇

---

# 🧠 1. Core Array & String Patterns

These are the most used in interviews.

### 🔹 Two Pointers

* Opposite ends (sorted arrays)
* Same direction (fast/slow)
* Partitioning (Dutch flag)

### 🔹 Sliding Window

* Fixed window (size k)
* Variable window (expand + shrink)
* Used for substring/subarray problems

### 🔹 Prefix Sum / Cumulative Sum

* Range queries
* Subarray sum problems

### 🔹 Difference Array

* Efficient range updates

### 🔹 Hashing / HashMap / HashSet

* Frequency counting
* Lookup optimization (O(1))

---

# 🔁 2. Searching Techniques

### 🔹 Binary Search

* Classic (sorted arrays)
* On answer (search space optimization)
* Variants:

  * Lower bound / upper bound
  * Rotated array search

### 🔹 Ternary Search

* For unimodal functions

---

# 🔄 3. Sorting Techniques

### 🔹 Comparison Sorts

* Merge Sort
* Quick Sort
* Heap Sort

### 🔹 Non-Comparison

* Counting Sort
* Radix Sort
* Bucket Sort

### 🔹 Special Patterns

* Custom sorting (with comparator)
* Sorting + Greedy combo

---

# 🔗 4. Linked List Techniques

### 🔹 Fast & Slow Pointer

* Cycle detection (Floyd’s algo)
* Middle node

### 🔹 Reversal Techniques

* Full reverse
* Reverse in k-groups

### 🔹 Dummy Node Pattern

* Simplifies edge cases

---

# 🌳 5. Tree & Binary Tree Techniques

### 🔹 DFS (Depth First Search)

* Preorder, Inorder, Postorder

### 🔹 BFS (Level Order)

* Queue-based traversal

### 🔹 Recursion / Divide & Conquer

* Break tree into subproblems

### 🔹 Binary Search Tree (BST)

* Ordered traversal logic

### 🔹 Tree DP

* Solve using child results

---

# 🌐 6. Graph Algorithms

### 🔹 Traversals

* BFS
* DFS

### 🔹 Shortest Path

* Dijkstra
* Bellman-Ford
* Floyd Warshall

### 🔹 Minimum Spanning Tree

* Kruskal
* Prim

### 🔹 Topological Sort

* Kahn’s Algorithm (BFS)
* DFS based

### 🔹 Union Find (Disjoint Set)

* Path compression
* Cycle detection

---

# 🎯 7. Greedy Techniques

* Always take the best local choice
* Works when problem has:

  * Optimal substructure
  * Greedy choice property

Examples:

* Activity selection
* Interval scheduling

---

# 🧩 8. Dynamic Programming (DP)

### 🔹 Types of DP

* Memoization (Top-down)
* Tabulation (Bottom-up)

### 🔹 Common Patterns

* 0/1 Knapsack
* Unbounded Knapsack
* Longest Increasing Subsequence (LIS)
* Longest Common Subsequence (LCS)
* DP on grids
* DP on trees

---

# 🔙 9. Backtracking

* Try all possibilities + prune
* Used in:

  * Permutations
  * Combinations
  * N-Queens
  * Sudoku

---

# 🔀 10. Divide & Conquer

* Break → Solve → Merge
* Examples:

  * Merge Sort
  * Quick Sort

---

# 📊 11. Heap / Priority Queue

* Top K elements
* Median in stream
* Scheduling problems

---

# 🧮 12. Bit Manipulation

* XOR tricks
* Subsets using bitmask
* Power of 2 checks

---

# 🔢 13. Mathematical Techniques

* GCD / LCM
* Sieve of Eratosthenes
* Modular arithmetic
* Fast exponentiation

---

# 🔍 14. Advanced Techniques

### 🔹 Monotonic Stack / Queue

* Next greater element
* Histogram problems

### 🔹 Segment Tree

* Range queries + updates

### 🔹 Fenwick Tree (BIT)

* Prefix sum optimization

### 🔹 Trie

* String prefix problems

### 🔹 Suffix Array / KMP / Z Algorithm

* Advanced string matching

---

# ⚡ 15. Misc Problem-Solving Patterns

* Meet in the Middle
* Sweep Line Algorithm
* Reservoir Sampling
* Randomized Algorithms

---

# 🧭 How to Actually Learn This (important)

Don’t try to learn all at once. Follow this order:

1. Arrays + Hashing
2. Two pointers + Sliding window
3. Binary search
4. Recursion + Backtracking
5. Trees + Graphs
6. DP
7. Advanced (Segment tree, Trie, etc.)
