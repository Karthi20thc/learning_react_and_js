Short answer: **Java arrays don’t have a built-in method to return an index** — you have to **search for it**.

---

# 🧠 Approach: Linear Search

> “Scan the array and return the index when you find the value”

---

## 💻 Basic Code

```java
public static int findIndex(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] == target) {
            return i;   // index found
        }
    }
    return -1; // not found
}
```

---

## 🧩 Example

```java
int[] nums = {2, 7, 11, 15};

System.out.println(findIndex(nums, 11)); 
```

👉 Output:

```
2
```

---

# ⚡ Important Notes

### 1️⃣ Returns first occurrence only

If duplicates exist:

```java
[3,3,4]
```

👉 returns index `0`

---

### 2️⃣ If not found

Returns:

```java
-1
```

---

# 🚀 When to use this

* Array is **unsorted**
* No preprocessing
* One-time lookup

---

# ⚠️ Optimization (if repeated searches)

If you need to find indices **many times**, use a HashMap:

```java
Map<Integer, Integer> map = new HashMap<>();

for (int i = 0; i < nums.length; i++) {
    map.put(nums[i], i);
}

// lookup
int index = map.get(target);
```

👉 This gives **O(1)** lookup
