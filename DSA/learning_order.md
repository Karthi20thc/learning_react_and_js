Good question — that sidebar is basically a **DSA roadmap**, but it’s not arranged in the best learning order. If you follow it randomly, you’ll struggle.

Here’s the **correct order to study (beginner → advanced)** 👇

---

# 🧠 Phase 1: Basics (Must be strong)

Start here — this builds your foundation.

1. **arrays**
2. **strings**
3. **mathematics** (basic logic, primes, gcd, etc.)
4. **recursion**

👉 Why:
Everything in DSA depends on these. If you skip this, nothing will click later.

---

# 🔄 Phase 2: Core Data Structures

Now learn how data is stored & manipulated.

5. **linkedList**
6. **stack**
7. **queue / deque**
8. **hashing**

👉 Focus on:

* Implementation
* When to use what

---

# 🌳 Phase 3: Trees & Searching

Now move to hierarchical structures.

9. **binarySearchTree**
10. **tree**
11. **binaryIndexedTree (Fenwick Tree)** *(optional early, can revisit later)*

👉 Also practice:

* **searching**
* **binary search (VERY IMPORTANT)**

---

# 🔢 Phase 4: Sorting & Problem Patterns

12. **sorting**
13. **two pointers / sliding window** (comes under arrays/strings but very important pattern)

---

# 🧮 Phase 5: Advanced Structures

14. **heap (priority queue)**
15. **segmentTree**

---

# 🔗 Phase 6: Graphs & Advanced Algorithms

16. **graph** ⭐ (VERY IMPORTANT)
17. **disjointSet (Union-Find)**
18. **greedy**

---

# 🧠 Phase 7: Dynamic Programming (Hard but powerful)

19. **dynamicProgramming**

👉 Do this only after:

* recursion ✔
* arrays ✔

---

# 🚀 Final Suggested Order (Clean Version)

If you want a simple linear path:

```
arrays
→ strings
→ mathematics
→ recursion
→ linkedList
→ stack
→ queue / deque
→ hashing
→ searching (binary search)
→ sorting
→ tree
→ binarySearchTree
→ heap
→ graph
→ disjointSet
→ greedy
→ dynamicProgramming
→ segmentTree
→ binaryIndexedTree
```
