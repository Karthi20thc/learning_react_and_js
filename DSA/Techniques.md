# 🧠 How to Think Like a Pro

When you see a problem, ask:

1. Is it **array/string contiguous?** → Sliding window
2. Is it **sorted?** → Binary search / two pointers
3. Is it **choices/combinations?** → Backtracking
4. Is it **optimization?** → DP / Greedy
5. Is it **connections?** → Graph / Union Find
6. Is it **range queries?** → Prefix sum
